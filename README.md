# Frontier Military

Minecraft **1.20.1**, Forge **47.2.0**, Java **17**. Совместим с OptiFine (стандартные JSON-модели, без миксинов и кастомных шейдеров).

## Что есть
- **23 блока**: ограждение с колючкой, защитная решётка, бетонный барьер, фонарь поста, мешки с песком (блок и стена), габион «Хеско», колючая проволока (замедляет и ранит), ящики боеприпасов и снабжения, топливная бочка, бункерный и камуфляжный бетон, бронелист, маскировочная сеть, полевая радиостанция, генератор, прожектор (свет 15), противотанковый «ёж», бронестекло, штабной стол с картой, стальной настил, предупреждающий знак. Ломаются нужным инструментом и выпадают, у всех есть рецепты.
- **Броня «Боевая экипировка»**: боевой шлем, бронежилет-плитоноска, боевые брюки, берцы (камуфляж, подсумки, наколенники). Защита между железом и алмазом, чинится усиленным волокном.
- **Усиленное волокно**: крафтится из 3 нитей и железного самородка; нужно для брони и маскировочной сети.
- **Служебный пистолет** (`frontiermilitary:pulse_sidearm`): магазин 12, ПКМ — выстрел.
- **АК-74**: магазин 30, автоматический огонь (удерживайте ПКМ), деревянное цевьё и приклад, магазин «слива».
- **Аптечка**: удерживайте ПКМ — анимация перевязки предплечья бинтом (7 стадий), лечит 4 сердца (как «Исцеление II»). Выпадает из ящиков снабжения, крафтится.
- **Ящик с боеприпасами** при ломании отдаёт патроны ко ВСЕМ видам оружия мода в случайном количестве; **ящик снабжения** — усиленное волокно, нити, сухпайки, аптечки (с Шёлковым касанием выпадает сам ящик).
- **Топливо и генератор**: пустая канистра + ПКМ по топливной бочке = канистра с бензином (в бочке 4 заправки, можно долить обратно). ПКМ канистрой по генератору — заправка (4 бака по ~3 мин). ПКМ пустой рукой — завод шнуром (анимация), генератор работает, дымит, гудит и даёт сигнал красного камня 15; ещё ПКМ — выключить. Прожектор рядом с ним (или с любым redstone-сигналом) загорается.
- **R** — перезарядка (клавиша переназначается). Пули — снаряды с трассером, попадание в голову ×1.5. Патроны: `pistol_ammo`, `rifle_ammo`.
- Предметы: полевой паёк (съедобный), патроны. Локализации: `ru_ru`, `en_us`.

## Анимации оружия
Первое лицо: отдача, смена магазина двумя руками, передёргивание затвора (9 состояний модели + 6 поз рук, переключаются свойством предмета `frontiermilitary:gun_state`). Третье лицо: двуручный хват.

## Сборка
```bash
gradle build        # Java 17, Gradle 8.8; JAR: build/libs/frontiermilitary-0.1.0.jar
```
GitHub Actions (`.github/workflows/build.yml`) делает то же самое и выкладывает JAR артефактом.

## Конфиг
`frontiermilitary-common.toml`: `weapons.pistolDamage` (7.0), `weapons.ak74Damage` (6.0).

## Генераторы ассетов (`tools/`)
Текстуры, JSON-модели и звуки созданы скриптами Python (numpy, Pillow, scipy, ffmpeg). Чтобы изменить вид — правьте скрипт и запускайте:
```bash
python3 tools/gen_block_textures.py && python3 tools/gen_block_models.py
python3 tools/gen_block_textures2.py && python3 tools/gen_block_models2.py
python3 tools/gen_item_textures.py && python3 tools/gen_armor.py
python3 tools/gen_pistol.py && python3 tools/gen_ak74.py && python3 tools/gen_sounds.py
python3 tools/validate.py   # проверка целостности ресурсов
```
`tools/preview.py` + `tools/preview_pistol.py` — собственный рендерер-превью моделей без запуска игры.

## Не реализовано
Генерация лагерей/баз, NPC-солдаты, обвесы, броня, техника (в конфиге остались заготовки).
